# DimDash Community

This is the official community space for **DimDash** — the smart dashboard dimmer for iPad.

> ⚠️ This repository contains **no source code**. DimDash is currently closed-source with plans to make it open-source. This repo exists solely for community support, bug reports, feature requests, and discussions.

---

## 🐛 Report a Bug

Found something broken? [Open a bug report →](https://github.com/NRCOM/DimDash-Community/issues/new?template=bug_report.md)

Please include:
- Your iPad model and iOS version
- Steps to reproduce the issue
- What you expected vs. what happened
- Screenshots or screen recordings if applicable
